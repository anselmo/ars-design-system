ARS Design System

Swiss-inspired design system. Zero border-radius. Barlow typeface. Restrained palette. Built on shadcn/ui primitives with Tailwind CSS.

05

Border Radius

Zero. Everywhere. This is a Swiss-style design system — all corners are sharp. Every Tailwind radius token is overridden to 0px.

--radius: 0px; --radius-sm: 0px; --radius-md: 0px; --radius-lg: 0px; --radius-xl: 0px; --radius-2xl: 0px; --radius-3xl: 0px; --radius-4xl: 0px;
0px
All components, buttons, cards, inputs, badges, dialogs — zero radius, no exceptions.

07

Elevation

Three shadow tiers reserved for floating surfaces. All tints derive from --l-black at varying alpha — never pure #000.

--shadow-popover
tooltips, dropdown menus (lowest lift)
--shadow-overlay
toasts, sticky notifications (medium)
--shadow-modal
dialogs, drawers (strongest, still restrained)
Doctrine. Static surfaces (cards, tables, sidebar, page-header) use NO shadow — depth comes from rule borders and paper layers. Shadows are reserved for floating surfaces only.

08

Z-index

Named tiers with 100-unit gaps so layered components inside one tier (e.g. nested popovers) can adjust without colliding with the next. Anything outside this scale is wrong — if you are tempted to hardcode 9999, you are stacking incorrectly.

TokenValueUse
--z-base0Default flow
--z-dropdown1000Menus, selects, comboboxes
--z-sticky1100Sticky table headers, sticky topbar
--z-overlay1200Modal backdrop, drawer scrim
--z-modal1300Modal content, drawer content
--z-popover1400Tooltips, popovers (above modals so they can attach)
--z-toast1500Notifications — always on top

09

Buttons

Six variants, four sizes. All buttons use 11px uppercase bold type with 0.06em tracking. Built with class-variance-authority (CVA) on Base UI primitives.

Accessibility. Body text and the focus ring meet WCAG AA on all surfaces. Brand-colour caveats: --l-orange and --l-green fail AA at body sizes — use them as accent fills, large text, or non-text indicators only. See tokens/colors.css for full guidance.

16

Forms

Form controls for textarea, select, checkbox, radio, switch, and file input. Each style is written against both native HTML form controls and Radix data-state="checked|unchecked|indeterminate" markup so consumers can choose either. Radio thumbs and switch thumbs are the only sanctioned border-radius: 50% exceptions in the system.
