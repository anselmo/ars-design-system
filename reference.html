Design System v1.0

Rapid Loyalty

Swiss-inspired design system for the Travel Loyalty Platform management console. Zero border-radius. Barlow typeface. Restrained palette. Built on shadcn/ui primitives with Tailwind CSS.

01

Token Role Where

05

Border Radius

Zero. Everywhere. This is a Swiss-style design system — all corners are sharp. Every Tailwind radius token is overridden to 0px.

--radius: 0px; --radius-sm: 0px; --radius-md: 0px; --radius-lg: 0px; --radius-xl: 0px; --radius-2xl: 0px; --radius-3xl: 0px; --radius-4xl: 0px;
0px
All components, buttons, cards, inputs, badges, dialogs — zero radius, no exceptions.

07

Inputs

Two input styles: underline (login, hero forms) and bordered (data entry, filters).

Underline Input

border-b-[1.5px] border-rule, focus: border-ink. 15px text. No background, no side borders.

Bordered Input

border border-rule, focus: border-ink. 13px text. Used in forms, filter bars, settings.
