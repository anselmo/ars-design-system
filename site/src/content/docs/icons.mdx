ARS ships with 68 curated [Iconoir](https://iconoir.com/) icons as an SVG sprite. Iconoir's minimalist, stroke-based style pairs naturally with ARS's Swiss design and zero-radius aesthetic.

## Setup

Copy the sprite into your HTML once (typically in your root layout):

```html
<body>
  <svg style="display: none" xmlns="http://www.w3.org/2000/svg">
    <!-- Copy contents of node_modules/@ars/design-system/icons/sprite.svg -->
  </svg>
  
  <!-- rest of your app -->
</body>
```

## Usage

Reference icons with `<svg><use>`:

```html
<!-- With design system icon slots -->
<svg class="icon empty-state-icon">
  <use href="#icon-search"/>
</svg>

<!-- Standalone with size variant -->
<svg class="icon icon-lg">
  <use href="#icon-check-circle"/>
</svg>
```

## Size Variants

| Class | Size | Use Case |
|-------|------|----------|
| `.icon-xs` | 12px | Inline text icons, dense UI |
| `.icon-sm` | 16px | Default, sidebar, alerts |
| `.icon-md` | 20px | Form labels, buttons |
| `.icon-lg` | 24px | Page headers, prominent actions |
| `.icon-xl` | 48px | Empty states, hero sections |

## Dark Mode

Icons inherit color via `currentColor`, so they automatically adapt to theme changes:

```html
<!-- Inherits from semantic color token -->
<svg class="icon" style="color: var(--muted-foreground)">
  <use href="#icon-info-circle"/>
</svg>
```

## Framework Examples

### React

```tsx
function EmptyState() {
  return (
    <div className="empty-state">
      <svg className="icon empty-state-icon">
        <use href="#icon-search"/>
      </svg>
      <h3 className="empty-state-title">No results</h3>
    </div>
  )
}
```
