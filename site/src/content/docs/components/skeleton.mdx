---
title: Skeleton
description: Loading placeholders in three shapes — text, rect, and circle.
---

`.skeleton` is the base class. All skeletons share the same `--l-light` fill and a 1.4s opacity pulse. Shape variants override layout only — never the fill or animation, so all skeletons on a page pulse in lockstep.

The pulse runs at 1.4s, slower than the `--motion-slow` (240ms) cap. Continuous animations need a slower cadence to avoid a frantic feel; this is a sanctioned exception to the motion token scale.

## Variants

| Class              | Shape              | Display       | Key dimensions                |
| ------------------ | ------------------ | ------------- | ----------------------------- |
| `.skeleton--text`  | Inline text line   | `inline-block`| height `1em`, width `100%`   |
| `.skeleton--rect`  | Block rectangle    | `block`       | height `80px`, width `100%`  |
| `.skeleton--circle`| Filled circle      | `inline-block`| `32×32px`, `border-radius: 50%` |

`.skeleton--circle` is the only genuine circle in the system — it uses `border-radius: 50%` like the radio dot and switch thumb. It is not a "rounded rectangle."

## Usage

```html
<!-- Text line placeholder -->
<span class="skeleton skeleton--text"></span>

<!-- Block rect (card, image) -->
<div class="skeleton skeleton--rect"></div>

<!-- Avatar placeholder -->
<span class="skeleton skeleton--circle"></span>
```

You can override `width` and `height` inline for non-standard dimensions.

## States

- **Normal** — 1.4s ease-in-out opacity pulse between `1` and `0.5`.
- **`prefers-reduced-motion: reduce`** — animation is set to `none`. The skeleton block is still visible but static, which still communicates "loading" without continuous motion.

## Tokens used

| Property  | Value / Token   |
| --------- | --------------- |
| Fill      | `--l-light`     |
| Animation | `ds-skeleton-pulse` 1.4s ease-in-out infinite |
