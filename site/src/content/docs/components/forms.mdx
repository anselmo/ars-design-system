---
title: Forms
description: Textarea, select, checkbox, radio, switch, and file input. CSS-only with Radix data-state interop.
---

Six form controls sharing the same focus ring, error, and disabled conventions. Each control supports both native HTML states (`:checked`, `:disabled`) and Radix UI `data-state` attributes — use whichever fits your stack.

## Controls

| Class         | Tag / role                                        | Size          | Notes                                                   |
| ------------- | ------------------------------------------------- | ------------- | ------------------------------------------------------- |
| `.textarea`   | `<textarea>`                                      | 13px, min-h 80px | 1px border, vertical resize                          |
| `.select`     | `<select>`                                        | 13px, h-32px  | Native select, custom SVG chevron (`--l-mid` stroke)    |
| `.checkbox`   | `<input type="checkbox">` or `role="checkbox"`    | 16×16px       | Sharp square, CSS-only checkmark, indeterminate support |
| `.radio`      | `<input type="radio">` or `role="radio"`          | 16×16px       | Circle (zero-radius exception), 8px dot on check        |
| `.switch`     | `<input type="checkbox" role="switch">` or Radix  | 32×16px       | Circular thumb slides 16px on checked                   |
| `.file-input` | `<input type="file">`                             | —             | `::file-selector-button` styled like `.btn-outline`     |

## Error state

`.input--error` applies on `.textarea` and `.select`. Border switches to `--l-red`; `:focus-visible` ring switches to `--l-red`.

## States

| State                                 | Effect                                                             |
| ------------------------------------- | ------------------------------------------------------------------ |
| `:focus-visible`                      | 2px `--ring` outline, 2px offset                                   |
| `.input--error` + `:focus-visible`    | 2px `--l-red` outline (textarea, select)                           |
| `:disabled` / `[data-disabled]` / `[aria-disabled="true"]` | Opacity 0.4–0.5, `not-allowed` cursor        |
| `:checked` / `[data-state="checked"]` | Both selectors fire the same styles on checkbox, radio, switch     |
| `[data-state="indeterminate"]`        | Checkbox only — horizontal 1.5px dash over `--primary` fill        |

## Usage

```html
<!-- Textarea -->
<textarea class="textarea" rows="4" placeholder="Notes…"></textarea>

<!-- Select -->
<select class="select">
  <option>Choose one…</option>
  <option value="a">Option A</option>
</select>

<!-- Checkbox — Radix-compatible button -->
<button class="checkbox" role="checkbox" data-state="unchecked" type="button" aria-checked="false"></button>

<!-- Radio — native -->
<input type="radio" class="radio" name="plan" value="monthly" />

<!-- Switch — Radix-compatible button -->
<button class="switch" role="switch" data-state="unchecked" type="button" aria-checked="false"></button>

<!-- File input -->
<input type="file" class="file-input" />
```

## Tokens used

- `--border` — control borders (default)
- `--ring` — `:focus-visible` outline
- `--primary` / `--primary-foreground` — checked fill (checkbox, radio, switch track)
- `--l-red` — `.input--error` border and focus ring
- `--l-rule` — switch track (unchecked)
- `--l-white` — switch thumb
- `--l-mid` — select chevron stroke, disabled text
- `--motion-fast` / `--ease-standard` — colour and transform transitions
