# Dark Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add warm-tinted dark mode to the Rapid Loyalty Design System, activated by both `prefers-color-scheme: dark` and a `.dark` class toggle.

**Architecture:** Override all `--l-*` primitive tokens and `--color-*` Tailwind aliases inside a `@media (prefers-color-scheme: dark)` block, then duplicate in a `.dark` selector (placed after for cascade precedence). Three button variants need explicit dark overrides. `reference.html` gets the same token overrides inlined plus a JS toggle button.

**Tech Stack:** CSS custom properties, `@media (prefers-color-scheme: dark)`, vanilla JS (reference page toggle only)

**Spec:** `docs/superpowers/specs/2026-03-22-dark-mode-design.md`


- [ ] **Step 3: Add inline `<script>` before `</body>` to sync toggle label with OS preference on load**

```html
<script>
  (function() {
    var btn = document.querySelector('.ds-theme-toggle');
    if (window.matchMedia('(prefers-color-scheme: dark)').matches && !document.documentElement.classList.contains('dark')) {
      btn.textContent = '☀ Light';
    }
    window.matchMedia('(prefers-color-scheme: dark)').addEventListener('change', function(e) {
      if (!document.documentElement.classList.contains('dark')) {
        btn.textContent = e.matches ? '☀ Light' : '● Dark';
      }
    });
  })();
</script>
```
